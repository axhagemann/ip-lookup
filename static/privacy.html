2. Processed Data and Purpose

This service displays your own IP address as well as network information derived from it. For this purpose, your IP address is processed, which is technically necessary to provide the service.

The following information is derived from the IP address:

  • Country, region, city (geolocation)
  • Internet Service Provider and Autonomous System (ASN)
  • Time zone and approximate geographical coordinates

This assignment is carried out exclusively using a database stored locally on the server (MaxMind GeoLite2). Your IP address is not transmitted to MaxMind or any other third parties. The result is cached in the server's memory for up to one hour so that repeat requests do not need to be looked up again.

The lookup is also available as an API and can be called from other websites. If you visit such a website, your IP address is processed in the same way.

The "Is It Up?" tool lets you check whether a website is reachable. For this, the server processes the address (URL) you enter, resolves it and requests it from its own IP address; the checked website receives no information about you. Only the domain is requested: any path or query string you enter is discarded before the check and never reaches the checked website. The address is used only for the check and is not stored; only in the event of technical faults can it appear in the server logs (Section 3).

3. Server Logs

With every request, data is automatically stored in server log files:

  • IP address
  • Requested URL and HTTP method
  • HTTP status code and response time
  • Timestamp

The log files are automatically deleted after 7 days.

4. Legal Basis

The processing of your IP address to provide the service, the processing of the address you enter into the "Is It Up?" tool, and the storage of your IP address in server log files are based on Art. 6 (1) (f) GDPR. Our legitimate interest lies in the secure, stable, and functional provision of our online service.

5. Audience Measurement

This website uses GoatCounter to measure how often its pages are visited. It is self-hosted and runs on the same server as this website. Both the counting script and the counting endpoint are served from this domain; no resources are loaded from third parties and no data is passed on to them.

The following data is processed:

  • Requested page (path) and page title
  • Referring page, if sent by the browser
  • Country of origin, derived from the IP address
  • Browser and operating system type, and screen width
  • A randomly generated session identifier, so that repeat views within one session are not counted more than once

Your IP address and your browser identifier (User-Agent) are not stored in the statistics. They are used solely to determine the country of origin and to associate your views with a randomly generated identifier for the duration of a session; only that identifier is stored. This association is held in the server's memory and is deleted at the latest eight hours after your last view; when the service restarts it is briefly written to the server and then carried forward. No recognition beyond this website takes place.

No cookies are set. No information is stored on or read from your device — with the single exception of an opt-out marker you set yourself (see below), which is read only in order to honour your objection and is therefore strictly necessary under Sec. 25 (2) no. 2 TDDDG. Consent under Sec. 25 (1) TDDDG is therefore not required.

The legal basis is Art. 6 (1) (f) GDPR. The legitimate interest lies in statistically evaluating usage in order to improve the content and operation of the website. This processing serves a purpose of its own and is separate from the processing described in Section 2, which provides the service itself.

Aggregated statistics are deleted after 12 months.

If your browser sends the "Do Not Track" (DNT) or "Global Privacy Control" (GPC) signal, we treat it as an objection under Art. 21 GDPR: such requests are discarded on the server and not counted. This requires nothing further from you and also works without JavaScript.

Independently of that, you may object to audience measurement here at any time. The setting is stored locally in this browser and applies until you undo it here or clear your browser data.
