// 2. Processed Data and Purpose

This service displays your own IP address as well as network information derived from it. For this purpose, your IP address is processed, which is technically necessary to provide the service.

The following information is derived from the IP address:

  • Country, region, city (geolocation)
  • Internet Service Provider and Autonomous System (ASN)
  • Time zone and approximate geographical coordinates

This assignment is carried out exclusively using a database stored locally on the server (MaxMind GeoLite2). Your IP address is not transmitted to MaxMind or any other third parties.

// 3. Server Logs

With every request, data is automatically stored in server log files:

  • IP address
  • Requested URL and HTTP method
  • HTTP status code and response time
  • Timestamp

The log files are automatically deleted after 7 days.

// 4. Legal Basis

The processing of your IP address to provide the service and its storage in server log files is based on Art. 6 (1) (f) GDPR. Our legitimate interest lies in the secure, stable, and functional provision of our online service.

// 5. No Cookies, No Tracking

This service does not set any cookies and does not use any analysis or tracking services.

// 6. Data Disclosure to Third Parties & Server Location

The website and the service are hosted by the web hosting provider Hetzner (Hetzner Online GmbH) on servers within the European Union (Finland). A data processing agreement (DPA) pursuant to Art. 28 GDPR has been concluded with Hetzner Online GmbH. Personal data is not transferred to third countries.

Data will not be passed on to other third parties unless there is a legal obligation to do so.

The geodatabase (GeoLite2) is automatically downloaded weekly from the servers of MaxMind (maxmind.com). No visitor data is transmitted during this process — only the server IP establishes contact with MaxMind. Individual user requests are not passed on to MaxMind.
